# Interview-Prep Directory Guidelines

All interview questions, answers, and study guides in this directory must adhere to the workspace rule:
[interview-prep.md](../.agents/rules/interview-prep.md)

## Summary of Rules
- **Direct 30-Second Spoken Answer**: Give a clear, verbal-friendly definition first.
- **Key Points (Rule of 3)**: 3 concise bullet points demonstrating technical depth.
- **Cross-Reference Learning Folder**: Always link to the related note in `Learning/` for deep concept background.
- **Interviewer Follow-ups**: Include common curveballs and follow-up questions.
- **Minimal Code / Command Snippets**: Practical, memorable syntax snippets.

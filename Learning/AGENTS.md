# Learning Directory Guidelines

All notes and explanations in this folder must follow the workspace rule:
[learning-notes.md](file:///Users/nayemuddinshaikh/Developer/.agents/rules/learning-notes.md)

## Summary of Rules
- **Simple English**: Use plain, everyday language. No unnecessary jargon.
- **Short & Direct**: Sentences under 15–20 words; paragraphs max 2–3 sentences.
- **Scannable**: Use bullet points, bold keywords, and quick summary tables.
- **Minimal Code**: Short, clear, working code examples with minimal boilerplate.
- **Standard Template**: Every note should have a 1-sentence summary, TL;DR takeaways, Why/When to use, Minimal Example, and Common Mistakes.
